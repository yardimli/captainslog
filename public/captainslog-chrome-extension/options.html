Captain's Log

Browsing sensor

The extension sends one active-site heartbeat per minute. Page paths and titles are not stored by the app.

Not connected

Save the app URL, then connect this extension to your signed-in account.

Optional sensor

Kindle reading progress

Sign in to Kindle Cloud Reader in Chrome, then open a book. The extension reads the progress shown by Kindle and sends only the book, progress, and time to Captain's Log. Amazon cookie values never leave Chrome.

Not connected

Open Kindle, sign in, and begin reading to create the first update.
